Alur Kerja Bolero Studio

  1. Klik tombol ☰ atau ⤢ untuk menyembunyikan panel agar peta tampil penuh satu layar.
  2. Klik ikon ⚙️ di bar kiri untuk mengatur simbol AutoCAD & kata kunci KML.
  3. Klik Import KML / KMZ di kanan atas untuk memuat data survei.
  4. Atur Skala Cetak pada tab Konversi lalu ekspor file .dxf + rekap BOQ.
